## Non-Negotiable Photographic Integrity Rules
1. **No Fake Identity**: Never present a generic bedroom as an actual named heritage hotel. Stays are labelled as "Illustrative Category Accommodation (Homestay / Boutique / Heritage)".
2. **Geographical Match**: Hawa Mahal shows Hawa Mahal, Lake Pichola shows Udaipur, Munnar shows tea gardens.
3. **Intentional Error States**: When an image link breaks or network fails, `SafeImage` displays a warm sand box (`#F7EFE4` / `#EBDCC7`) with an icon and "Photo unavailable", never a mismatched stock mountain photo.
